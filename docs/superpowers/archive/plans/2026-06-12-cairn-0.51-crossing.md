# cairn 0.51.0 crossing (Pass 16.2)

**Status: DONE 2026-06-12 (commits a448c0c, 2bd5ddb, 16000f5). Live proofs recorded in docs/STATUS.md and the deploy run.**

## Why

The engine published `0.51.0` on 2026-06-12 and 907.life is the last site on the old admin seam,
pinned `^0.36.0`. This pass crosses the whole `0.37.x..0.51.0` window in one move, the same shape
ecxc-ski proved on 2026-06-12: the eighteen-file admin shim tree becomes the two-file catch-all
mount plus the composer, the floors rise, and the editor gains the iframed preview wired to this
site's real stylesheet.

## Survey (run 2026-06-12 against the live repo; do not re-derive)

What the window breaks for this site:

- **0.50.0 single-mount.** The route factories the composer uses today (`createContentRoutes`,
  `createAuthRoutes`, `createEditorRoutes`, `createNavRoutes`) give way to one
  `createCairnAdmin(runtime)`. The engine's `parseAdminPath` serves every view 907 has today,
  including `nav` and `editors`. The `0.39.0` shim-action additions are moot; the shim tree is
  deleted whole.
- **`app.d.ts`.** The hand-declared `App.Locals.editor` ships with the engine now; swap it for
  `import '@glw907/cairn-cms/ambient'` and keep the site's own `Platform.env` block. Import
  `AuthEnv` from `@glw907/cairn-cms/sveltekit` (the ecxc shape).
- **Floors.** kit `^2.12` (0.41.0) and svelte `^5.56.3` (0.51.0, now an enforced peer range).
  907 declares `^2` and `^5`; raise both explicitly so the lockfile re-resolves.

What survives unchanged (verified against the 0.51.0 exports): `createSiteIndexes` (only the
singular `createSiteIndex` was renamed), `createPublicRoutes`, `healthLoad`, `createAuthGuard`,
and the whole delivery surface (feeds, sitemap, robots, `CairnHead`). `svelte.config.js` already
carries `csrf: { checkOrigin: false }` and `wrangler.toml` already has `[observability]` from the
0.36 retrofit. `hooks.server.ts` needs no change.

What the window adds that this pass wires: the publish workflow and status badges, the redesigned
editor, the login `send_error`/`throttled` states, the doctor improvements, and the `preview`
knob. 907's content region nests `main.container.mx-auto.px-4.max-w-3xl.py-8 >
article.post-detail > div.post-body`, and every content rule in `app.css` is a flat `.post-body`
descendant selector, so the frame reproduces the chain as
`bodyClass: 'container mx-auto px-4 max-w-3xl py-8 post-detail'` over
`containerClass: 'post-body'`. Posts is the only concept, so no `byConcept`. The site is Tailwind
4 + DaisyUI 5, every one of those classes already appears in site markup (so the compiled sheet
has them), and a Vite `?url` import of `src/app.css` resolves the hashed asset. The frame's
document carries no `data-theme`, so the preview renders the silk default; acceptable, and noted
here deliberately.
